Privacy

Simple by design.

This website is currently a static portfolio and proposal experience hosted on GitHub Pages. The interactive project brief is generated locally in your browser.

No project brief data is transmitted or stored by this site in the current version. Copying or downloading a brief happens on your device.

Do not enter patient-identifiable health information, clinical records, passwords, API keys or other confidential credentials into the public project brief.

The website may load externally hosted font files and link to third-party websites such as GitHub, Instagram and live project sites. Those services apply their own privacy policies when you visit them.

If a secure enquiry backend, analytics or client portal is introduced later, this page will be updated before those features are treated as production contact channels.
